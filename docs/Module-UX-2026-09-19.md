# Module usability redesign — 19 September 2026

## What changed

Shared presentation now reaches all 33 authenticated module entries: rounded section cards with relevant icons, structured table headers and row highlighting, readable status pills, icon-assisted actions, and wrapping tab bars. Mobile dialogs stay within the viewport. Navigation returns each new page to the top.

The sidebar uses SVG icons with distinct section colors and short hover/focus animations. Reduced-motion preferences disable those animations. A searchable Modules panel shows cards with short explanations and only the destinations the signed-in account can access.

Team Overview separates Staffing, Approvals, Tasks and Performance. Counts remain scoped; staffing coverage uses accepted versus required places; rating bars retain numeric values and sample counts. Task owners are chosen explicitly rather than automatically assigning the first person in a list. Errors are shown in the task panel.

Leave separates requests, balances, the request form and calendar. Summary labels distinguish employee requests from reviewer decisions. Recruitment separates requisitions, candidates, interviews and offers. Payroll shows a short workflow, scoped counts and currency-separated totals; detailed calculation guidance is expandable, and employee guidance describes viewing payslips. Operational Setup uses the same metric cards.

Dark mode now defines readable slate surfaces and contrasting primary colors across shared controls. Backend policies, access checks, approval requirements and salary/leave calculations are unchanged. No database migration is needed.
